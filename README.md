# 刘海聊天 Notch Chat

一个用 Swift、AppKit 和 WKWebView 编写的 macOS 刘海聊天面板。把常用 AI 网页放到屏幕顶部，随时展开聊天。

## 功能

- 在 ChatGPT、DeepSeek、Gemini 网页之间切换。
- 鼠标悬停展开、移开收起，支持固定面板与 Esc 收起。
- 外侧柔和光晕和呼吸动画，支持主题与效果切换。
- 保存各服务在 App 内的网页登录状态。
- 可将当前服务在系统浏览器中打开。

## 构建运行

需要 macOS 14 或更新版本，以及 Xcode Command Line Tools。首次可运行 `xcode-select --install` 安装编译工具。

```sh
git clone https://github.com/zhouyu713/notch-chat.git
cd notch-chat
zsh build.sh
open 刘海聊天.app
```

构建结果为当前目录下的 `刘海聊天.app`，可手动复制到“应用程序”。脚本使用本机临时签名，未提供 Apple 开发者公证安装包。

## 使用

启动后把鼠标移到屏幕顶部中央，展开聊天面板。选择服务后使用自己的账号登录。菜单提供展开、收起、主题、效果、自定义侧边文字和退出操作。

## 当前状态与限制

这是 v0.27 原型，视觉效果仍在迭代。不同屏幕、缩放比例及没有刘海的 Mac 上的体验需要进一步验证。

嵌入的是第三方网站，不是 API 客户端；网站布局变化可能影响显示。部分服务可能拒绝内嵌浏览器登录（例如 Google OAuth），此时请使用“在浏览器中打开”。App 内登录状态与系统浏览器不保证互通。各服务账号、订阅及可用性由对应服务提供。

## 项目文件

- `main.swift`：窗口、刘海面板、光晕和网页视图。
- `build.sh`：编译、生成 App 和本机临时签名。
- `AppIcon.icns` / `icon.swift`：应用图标与图标生成源码。

仓库不包含个人聊天记录、网页缓存、Cookie 或账号配置。
